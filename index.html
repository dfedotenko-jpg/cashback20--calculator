Логика расчёта: общее количество чеков считается с учётом возвратов: продажный чек = +1, возвратный = −1. UPT = итоговые единицы с учётом возвратов / общее количество чеков с учётом возвратов. Повторная покупка — второй и последующий продажный чек одной дисконтной карты в одном магазине за один день. Возвраты исключаются из показателей акции. Списание определяется по колонке «Скидка бонусы»: любое ненулевое значение. Возвраты не участвуют в показателях эффективности акции.
